# Tony Closes

Website for **Tony Closes** — my journey into a remote, high-ticket sales (closing) career. Built with [Astro](https://astro.build).

## About

I'm building a career as a remote high-ticket closer: running sales calls from anywhere, working with offers priced in the thousands, and earning on commission. This site documents that path and serves as my home base for:

- **Who I am** — background, story, and what I bring to a sales team
- **The craft** — what I'm learning about discovery, objection handling, and closing
- **Progress** — a build-in-public log of calls, lessons, and milestones
- **Work with me** — a way for offer owners and sales teams to get in touch

> The site is in early development. Content and structure will change as it grows.

## Tech Stack

- [Astro](https://astro.build) — static-first site framework
- Node.js 22+ and npm

## Getting Started

```sh
git clone https://github.com/ExpatBuildr/tonycloses.git
cd tonycloses
npm install
npm run dev
```

The dev server runs at `http://localhost:4321`.

## Project Structure

```text
/
├── public/          # Static assets (favicon, images)
├── src/
│   └── pages/       # File-based routes (index.astro = home page)
├── astro.config.mjs
└── package.json
```

## Commands

| Command           | Action                                       |
| :---------------- | :------------------------------------------- |
| `npm install`     | Install dependencies                         |
| `npm run dev`     | Start the dev server at `localhost:4321`     |
| `npm run build`   | Build the production site to `./dist/`       |
| `npm run preview` | Preview the production build locally         |
